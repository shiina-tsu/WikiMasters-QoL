This script was made to be used in the Tampermonkey browser extention. 
Install [tampermonkey](https://www.tampermonkey.net/)
Install [userscript](https://github.com/shiina-tsu/Wiki-Masters-QoL/raw/main/master.user.js)

Quality of life script for wiki-masters.com, made in a unoptimized, overcomplicated and unprofessional way, because I sucks. :(

Anyway this script offer the ability to see any average price of any card directly on the card itself in collection and market section.
Quite useful to quicktly sort and make decision.

The script could be qualified of "It does the job".

I plan to do updates in the future for cool stuffs.
